Connect a coding assistant (MCP)

While DeviceDeck is open, assistants like Claude Code or Cursor can open pages on all your devices, read them, click, type and take screenshots, so they can check their own layout fixes on phones, tablets and computers. It only listens on this computer.

Claude Code — run once in a terminal

claude mcp add --transport http devicedeck http://127.0.0.1:12721/mcp

Cursor, VS Code and others — add to the MCP settings

{ "mcpServers": { "devicedeck": { "url": "http://127.0.0.1:12721/mcp" } } }

Tools it offers: get_status, get_app_state, list_devices, set_devices, navigate, reload, screenshot, read_page, click, type_text, run_script and check_layout (finds horizontal scrolling, elements wider than the screen, tiny text and small tap targets).

It only works while DeviceDeck is open. To check that it's running: curl http://127.0.0.1:12721/health

Emulation setup

Web version

Fake the device on any website — get the DeviceDeck Windows app

A web page isn't allowed to change how other websites see your browser. The installed Windows app has no such limit: every device is a real browser view that tells every website it is that phone, tablet or computer, and no site refuses to show. Nothing to set up — install and go.

Download the app (Windows, macOS, Linux)

In this web version

  1. Every site is shown at the exact screen size of each device, with light/dark mode. That alone already triggers your responsive layouts.
  2. Your own site: add this line as the first thing inside <head> while you develop. In each pane the page will then see that device's browser name (user agent), system, touch screen, screen size, pixel density, pointer and hover — and scrolling, links, clicks and typing stay in sync across panes.

    It does nothing when the page is opened normally, so it's safe during development. Prefer no outside link? or download it and serve it yourself.

  3. A single HTML file? Use "Open file" or "Paste HTML" — faking is applied automatically.

In the web version, websites you don't control only get the screen size and light/dark mode, and some of them refuse to be shown inside another page at all. The Windows app removes both limits.
